Find helpers near your location with an easy-to-use search interface.

== Description ==

Nearby Helpers Finder allows users to search for helpers in their area using their address. Features include:

* Address autocomplete using Google Maps
* Configurable search radius
* Profile pictures for helpers
* Distance calculation
* Responsive design

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/nearby-users-finder`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Use the Settings->Helpers screen to configure the plugin
4. Place the shortcode `[nearby_helpers]` in your pages or posts

== Frequently Asked Questions ==

= How do I add helpers? =

Go to Helpers > Add New Helper in your WordPress admin panel.

= How do I change the search radius? =

Go to Helpers > Settings and adjust the "Search Radius" value.
